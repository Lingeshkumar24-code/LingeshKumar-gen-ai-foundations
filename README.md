## 🚀 Tasks Overview

| Task | Title & Topic | Tech Stack |
|---|---|---|
| **Task 01** | Vectorized Scaled Dot-Product Attention | Pure NumPy, Python 3.10+ |
| **Task 02** | Custom BPE Tokenizer & Autoregressive Causal LM | PyTorch, NumPy, Python |
| **Task 03** | Local 7B LLM Quantization & Logit Extraction | PyTorch, HF Transformers |
| **Task 04** | In-Memory HNSW Vector Indexing | Python, NetworkX, SciPy, NumPy |
| **Task 05** | Custom Transformer Backpropagation Engine | PyTorch (`requires_grad=False`), NumPy |
| **Task 06** | High-Throughput Async RAG & Cross-Encoder Reranking | FastAPI, LangChain, FAISS, PyTorch |
| **Task 07** | LoRA Matrix Projection Fine-Tuning | PyTorch, Hugging Face PEFT |
| **Task 08** | Multi-Agent Collaborative Blackboard Swarm | AutoGen, Redis, PostgreSQL |
| **Task 09** | Real-Time Vector Stream Ingestion | Apache Kafka, PySpark, Vector DB |
| **Task 10** | Denoising Diffusion Probabilistic Model (DDPM) | PyTorch, Diffusers, NumPy |
| **Task 11** | Prompt Injection Guardrails & Attack Simulator | NeMo Guardrails, Transformers |
| **Task 12** | Vision-Language Dual-Encoder Knowledge Distillation | PyTorch, TorchVision, SciPy |
| **Task 13** | Direct Preference Optimization (DPO) Alignment | PyTorch, TRL, Accelerate |
| **Task 14** | Custom CUDA Kernel Integration (SwiGLU) | C++, CUDA Toolkit, PyTorch C++ Extensions |
| **Task 15** | Enterprise LLM Gateway with Dynamic Rate-Limiting | FastAPI, Redis, Prometheus |
